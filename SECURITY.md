# Политика безопасности

Не публикуйте в issue, Pull Request, логах, скриншотах или демонстрационном
CSV:

- токен Telegram-бота;
- пароль или полный URL прокси;
- содержимое `.env`;
- файлы `tasks.db`, резервные копии и CSV с реальными задачами;
- Telegram user ID и другие персональные данные.

Если секрет случайно попал в GitHub:

1. Немедленно отзовите или обновите секрет у соответствующего сервиса.
2. Удалите секрет из локальной рабочей копии и истории Git при необходимости.
3. После ротации проверьте файлы репозитория повторно.

Сообщения об уязвимостях следует отправлять владельцу репозитория приватно,
через безопасный канал связи. Не публикуйте подробности эксплуатации до
готовности исправления.
