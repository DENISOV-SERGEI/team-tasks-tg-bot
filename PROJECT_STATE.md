# Состояние проекта: Telegram-бот командных задач

## 1. Стек и запуск
- **Расположение:** проект находится непосредственно в `VPb06/`.
- **Язык:** Python 3.10+.
- **Telegram-фреймворк:** aiogram 3.x.
- **База данных:** SQLite через `aiosqlite`, чтобы SQL-запросы не блокировали цикл событий бота.
- **Настройки:** токен читается из локального `.env` с помощью `python-dotenv`.
- **Планируемый запуск:** `python main.py` из `VPb06/`.
- **Планируемый запуск тестов:** `python -B -m unittest discover -s tests -v`.

## 2. Архитектурный план

Направление зависимостей: `ui -> core <- driver`. `main.py` связывает слои и запускает приложение. Импорт модулей не должен подключаться к Telegram или создавать базу данных.

### Слои и основные классы
- **`core/models.py` — `Task`:** доменная сущность с ID, текстом, автором и временем создания.
- **`core/ports.py` — `TaskRepository`, `TaskExporter`:** протоколы хранения задач и формирования CSV. Ядро не зависит от aiogram и SQLite.
- **`core/errors.py`:** понятные доменные ошибки, например ошибка пустого текста задачи.
- **`core/services.py` — `TaskService`:** проверяет текст, делегирует атомарное добавление репозиторию, получает общий список и делегирует CSV-экспорт портам.
- **`driver/sqlite_task_repository.py` — `SQLiteTaskRepository`:** асинхронно инициализирует таблицу `tasks` со столбцами `id INTEGER PRIMARY KEY AUTOINCREMENT`, `text TEXT NOT NULL`, `user TEXT NOT NULL`, `created_at TEXT NOT NULL`, `category TEXT NOT NULL DEFAULT 'Общее'`, `status TEXT NOT NULL DEFAULT 'Новая'`; атомарно определяет дубли при добавлении и реализует чтение и смену статуса.
- **`driver/csv_exporter.py` — `CsvTaskExporter`:** формирует CSV в памяти, не создавая временный файл.
- **`ui/telegram/handlers.py`:** обработчики команд Telegram, которые вызывают сервис и отправляют ответы.
- **`ui/telegram/states.py`:** FSM-состояния добавления: ввод текста и выбор категории.
- **`ui/telegram/formatters.py`:** оформляет список и разбивает большой вывод на сообщения допустимой длины.
- **`config.py`:** загружает токен и путь к SQLite из окружения/`.env`.
- **`main.py`:** собирает зависимости, создаёт таблицу, ждёт доступности Telegram, настраивает меню команд (сбой не критичен), регистрирует роутеры и запускает polling; при остановке закрывает ресурсы.

### Команды и поведение
- `/start` — приветствие и краткая инструкция.
- `/add` — пошаговое добавление через FSM: бот просит текст, затем предлагает категорию reply-клавиатурой; новый текст получает статус «Новая», повтор — «Старая».
- `/list` — выводит общий список задач по времени добавления; длинный список отправляется несколькими сообщениями.
- `/done <номер>` — отмечает задачу выполненной; при ошибке в номере бот подсказывает формат.
- Допустимые статусы ограничены значениями «Новая», «Старая» и «Выполнена».
- `/list_csv` — отправляет CSV-файл со всеми задачами.
- Автор сохраняется как Telegram username, а если он не задан — как числовой Telegram user ID.
- Время создания хранится в UTC в ISO 8601.
- Список общий для пользователей бота; роли и персональные списки в минимальный объём не входят.

## 3. Зависимости
- `aiogram>=3.13,<4.0` — асинхронное взаимодействие с Telegram Bot API.
- `aiosqlite>=0.20,<1.0` — асинхронный драйвер SQLite.
- `python-dotenv>=1.0,<2.0` — загрузка локальных переменных окружения.
- CSV, буфер в памяти и `sqlite3`-форматирование дополнительных пакетов не требуют.

## 5. Важные ограничения
- Не записывать токен в код или логи; локальный `.env` исключён из Git.
- Инициализировать БД и запускать polling только из точки входа, не при импорте.
- Использовать временные SQLite-файлы в тестах.
- Уведомления, расписания и разграничение задач по пользователям не входят в запрошенный минимальный объём.
- Сохранять существующее содержимое `VPb06/venv/`.
- `venv/` создан под Windows (Python 3.13). В WSL запускать его так: `PYTHONIOENCODING=utf-8 ./venv/Scripts/python.exe -B -m unittest discover -s tests -v`; системный Python 3.14 зависимостей не содержит.
- Старый токен из `.env.example` мог попасть в историю Git, поэтому его следует отозвать у `@BotFather` и выпустить новый.
